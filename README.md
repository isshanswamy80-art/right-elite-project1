# Right Elite Website

A responsive React implementation of the supplied Right Elite Figma design.

## Pages

- Home
- About
- Services
- Projects
- Contact

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated production files are written to `dist/`.

## Tech stack

- React 19
- TypeScript
- Vite
- React Router
- Local Inter and Lora font packages

The layouts are optimized for desktop, tablet, and mobile viewports, with responsive navigation and image treatment.
